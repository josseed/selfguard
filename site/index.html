Your laptop is the softest target
in your supply chain.

It holds your npm, GitHub and cloud tokens, runs install scripts from strangers, and now lets AI agents execute commands for you. Malware that lands there does two things: it makes sure it runs again, and it takes the credentials lying around. Scanners in the cloud never see any of it.

What it guards

Four layers, one guard.

Every check runs locally and reads files as data. Nothing from your projects is ever executed.

Dependencies of every repo

Every project on your machine, checked against OSV.dev, including the ones you haven't opened in months. Malicious packages (OpenSSF MAL-*) outrank any CVE, and you get one upgrade target per package.

npm · pnpm · yarn · bun · uv · Poetry · Cargo · Go modules

CI workflows

The GitHub Actions your workflows use: compromised actions, references not pinned to a commit SHA, and script injection from untrusted input.

.github/workflows/*.yml

AI agents

MCP servers configured for Claude, Cursor, VS Code, Codex and more, without reading their secrets. Repo files that run code when you open the repo: agent hooks, autorun VS Code tasks, API overrides, and hidden Unicode in instruction files.

It checks the machine, not just the code on it.

No network, nothing executed. selfguard reviews what starts at login, what your shell runs, where your package managers install from and which tokens sit on disk, then tells you what to do instead.

  • Launch items that run from /tmp, hidden folders or Downloads, or use an Apple label
  • curl | sh, DYLD_INSERT_LIBRARIES and NODE_OPTIONS hooks in shell startup files
  • Dismiss what you put there on purpose. It stays listed and never alerts.

How it works

Set it up once. It tells you on its own.

Alerts without asking

Re-checks seconds after a lockfile or config changes, syncs new advisories on a schedule, and sends a "✓ fixed" when you clean something up.

Attacks first

Malicious packages and anything that looks like an attack open a dialog that stays on screen, even in a repo you cloned a minute ago.

Tells you what to do

"Upgrade lodash to 4.18.0", "pin this action to a SHA", "use a short-lived token". Not a wall of advisories.

Finds your projects

Searches your home folder, skips caches and cloud drives, and finds agent worktrees. cd into a project and it's registered.

Signal over noise

Only active checkouts alert you. The first scan is a baseline, so you hear about what's new, not the backlog.

All your machines

Other Macs connect over Tailscale with a pairing code. Servers use SSH with a dedicated, read-only key. Alerts name the machine.

Meet Bastion

A 16-bit castle guard who acts out what changed.

He lives in the Mac app's dashboard and menu bar. One look tells you how your machine is doing.

Safe by design

A guard that never phones home with your secrets.

name@version

The only network call: ecosystem, name and version of your dependencies to OSV.dev. No paths, repo names or code. Machine checks make no request at all.

0 deps

Zero runtime dependencies, published to npm with provenance. It never executes code from your projects.

never the values

Tokens, MCP secrets and hidden text are detected by presence only and never shown or stored. State lives in ~/.selfguard, readable only by you.
